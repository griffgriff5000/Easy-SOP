# Assisted document revision

Approved in conversation: a separate side-by-side workspace, old Word or PDF on the left and new Word on the right. Inspect paragraphs, headings, tables and artwork. Suggest destinations using local analysis and optional local AI. Every placement requires approval; allow editing and reordering, including assistant requests. Track unplaced/suggested/approved/excluded source elements. Preserve originals; export a separate revised DOCX and transfer report. New template supplies its structure and styles. Uncertain PDF extraction, scanned pages and unsupported Word objects must remain visible for review.

Implementation choices: offline structural matching is always available. Optional Ollama integration uses loopback only, installed local models and constrained JSON proposals. No automatic downloads or cloud calls. PDF extraction uses pdfplumber; rendered page/region images retain visual evidence, including scans. Scans can be transferred as page artwork or manually transcribed; automatic OCR is not bundled. Desktop Word provides the final in-place editor using the existing owned-session lifecycle. Revision workspaces save separately from SOP projects and retain source/template snapshots and approval state.
