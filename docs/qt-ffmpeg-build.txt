# Corresponding sources for the bundled Qt FFmpeg backend

These shared libraries are supplied unmodified by PySide6 6.12.0 for Windows x64. `BINARY_CONFIGURATION.txt` contains the version, license and complete build configuration obtained from the actual avutil DLL. The archives contain FFmpeg n9.0.1 upstream source and zlib 1.3.1 source. FFmpeg is LGPL 2.1 or later; the license texts and upstream LICENSE.md are alongside this file and inside its source archive. zlib's license is inside its source archive. SOURCES.json records upstream locations and local SHA-256 digests.

Qt's upstream provisioning script downloads FFmpeg 9.0.1 from ffmpeg.org with SHA-1 89c318905212e6b67e10e42ab10ab8007e0aefda, then builds without source patches. This bundle uses the upstream GitHub n9.0.1 source archive of the same version (archive metadata/compression differs). It is not a Gyan source bundle. The standalone exporter is a separate optional download from its distributor, not included in this installer.

To rebuild: install MSVC 2022 x64 build tools, Windows SDK and MSYS2 with make, diffutils, perl and nasm available. Extract zlib 1.3.1 to C:/zlib-1.3.1 and FFmpeg n9.0.1 to C:/FFmpeg-n9.0.1. The included common_windows_zlib.ps1 describes Qt's full preparation and nmake steps, including its Makefile.msc and zconf.h compatibility patches, and builds zlib under build/amd64. The included common_windows_install-ffmpeg.ps1 and shared configuration describe the FFmpeg configure/make steps. Restore the scripts' relative paths from their common_windows_ / common_shared_ prefixes when executing them, or run the documented configure command in BINARY_CONFIGURATION.txt from an x64 VS developer environment with MSYS2. Run make install. No --enable-gpl or --enable-nonfree is used for these Qt DLLs. Paths may be adapted to your environment.

Close the application before replacing matching avcodec, avformat, avutil, swresample and swscale DLLs in _internal/PySide6 with ABI-compatible rebuilt versions. Preserve backups so you can restore the prior libraries. This application does not prohibit reverse engineering to debug modifications to LGPL libraries. Qt source/build scripts are available at https://github.com/qt/qt5/tree/6.12.0/coin/provisioning and FFmpeg sources at https://github.com/FFmpeg/FFmpeg/tree/n9.0.1.
